## Upload ke GitHub
1. Extract ZIP.
2. Upload `index.html` langsung ke ROOT repository.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`.
6. Folder: `/ (root)`.
7. Save.

Catatan: kandidat, angka, wilayah, dan hasil pada prototype adalah DATA SIMULASI.
